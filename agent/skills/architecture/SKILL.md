# Architecture analysis

1. Read PROJECT_MEMORY.md and relevant architecture/config files.
2. Search entry points, imports, callers, routes and data models before opening many files.
3. Trace the flow across modules; cite paths and symbols.
4. Separate observed architecture from inferred relationships.
5. Propose the smallest coherent design; note migrations, security boundaries, failure modes and rollback.
6. Check maintenance, license, runtime compatibility, bundle size and OSV before adding dependencies.
