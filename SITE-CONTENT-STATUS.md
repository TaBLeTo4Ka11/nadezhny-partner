# Состояние сайта «Надёжный партнёр»

## Реализовано в рабочей ветке gpt6/site-completion

- Главная страница, адаптивная навигация и SEO-метаданные.
- Светлый дизайн с графитовой типографикой и красными акцентами.
- Каталог из 6 групп и 19 пунктов с поиском.
- Отдельные локальные страницы для каждого пункта каталога по адресу /catalog/<slug>/.
- Динамические title и description для страниц категорий и информационных разделов; canonical URL для внутренних страниц и главной.
- `robots.txt` и XML sitemap на 24 URL (главная, 19 категорий и 4 информационные страницы).
- Пять подтверждённых товарных позиций банковских передаточных устройств со ссылками на исходные карточки.
- Раздел о компании и четыре этапа производства.
- 13 фотографий производства, 11 фотографий объектов, три отзыва, шесть логотипов партнёров.
- Контактные данные, карта, режим работы и реквизиты, перенесённые с исходного сайта.
- Отдельные информационные страницы склада, доставки и установки, вакансий и полезных материалов.
- Форма КП с полями контактов, описанием задачи, выбором файла и обязательным согласием. Форма открывает почтовое приложение; файл необходимо приложить вручную.
- Сборка GitHub Actions включена для рабочей ветки.

## Ограничения и точность

Не выдумывать характеристики, цены, сертификаты, сроки, гарантии, складские остатки или юридические формулировки. Пять подтверждённых товарных позиций не являются полным каталогом.

## Запуск

Node.js 20+, затем npm install и npm run dev. Production-сборка: npm run build.
