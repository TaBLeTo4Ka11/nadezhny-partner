# Состояние сайта «Надёжный партнёр»

## Реализовано в рабочей ветке gpt6/site-completion

- Главная страница с адаптивной навигацией, каталогом, блоками о компании, производстве, галереей, отзывами, контактами и блоком связи для запроса КП.
- Светлый дизайн с графитовой типографикой и красными акцентами.
- Структура каталога восстановлена до 17 категорий по навигации официального сайта, открытой 03.11.2026: 5 категорий противопожарных преград, 6 входных дверей, 3 бронированных дверей, 2 деревянных дверей и 1 категория фурнитуры. Это подтверждённый список категорий, но не полный перечень отдельных товаров.
- Отдельные локальные маршруты для 17 категорий: `/catalog/<slug>/`; известные маршруты явно переписываются на SPA; для неизвестных адресов добавлена статическая `public/404.html`. Ожидается HTTP 404, но фактический статус ещё не проверен на Vercel Preview.
- Поиск по названиям категорий и группам; совпадение с названием группы показывает все категории этой группы. Добавлены страницы `/o-kompanii/` и `/kontakty/` по доступным снимкам официального сайта. Добавлена локальная карточка ЛТ-21 с пометкой об архивной давности источника и необходимости подтверждения параметров.
- В исходной индексированной категории «Банковские лотки» подтверждены пять названий товаров. Полные карточки четырёх позиций не удалось повторно открыть; для ЛТ-21 создана локальная карточка по индексированному снимку с предупреждением о необходимости подтверждения параметров.
- В текущих данных есть пять ссылок на изображения продукции, 11 фотографий объектов, 13 фотографий производства, три отзыва и шесть логотипов партнёров. Все изображения пока внешние; 24 URL фотографий объектов/производства содержат размеры миниатюр `225x300` или `169x300`. Оригиналы не скачаны и не проверены.
- Отдельные информационные маршруты склада, доставки и установки, вакансий и полезных материалов. Их тексты не восстановлены: страницы честно сообщают об этом и показывают прямые контакты компании.
- Динамические title/description и canonical для категорий, карточки товара и информационных страниц; неизвестные адреса получают `noindex, nofollow`.
- Категории, карточка ЛТ-21 и информационные страницы-заглушки помечены `noindex, follow`, пока каталог и контент не будут полностью восстановлены. Страницы `/o-kompanii/` и `/kontakty/` имеют подтверждённый контент и включены в sitemap.
- `robots.txt` указывает на XML sitemap.
- XML sitemap содержит главную страницу, `/o-kompanii/` и `/kontakty/`. Незавершённые категории, карточки товаров и юридические заглушки в sitemap не включены.
- Для формы КП подготовлен серверный endpoint `api/contact.ts`: проверка Origin, валидация, ограничение размера, honeypot и пересылка на HTTPS webhook с Bearer-секретом. Клиентская форма по умолчанию выключена флагом `VITE_CONTACT_FORM_ENABLED`; для активации нужны утверждённая политика/согласие, владелец-подтверждённый HTTPS webhook и секреты Vercel `CONTACT_WEBHOOK_URL` / `CONTACT_WEBHOOK_SECRET`. Пока форма выключена, сайт показывает прямые контакты. Файловые вложения не подключены; распределённый rate limit ещё требуется настроить на платформе или webhook-приёмнике.
- Внутренние ссылки на старые страницы товаров и разделов убраны из активного интерфейса, чтобы после переключения домена не вести на сам новый сайт или на несуществующие маршруты.
- Маршруты `/privacy-policy/` и `/kuki/` созданы как честные страницы-заглушки `noindex`; они не являются действующими юридическими документами.
- Зафиксированы версии зависимостей в `package-lock.json`; GitHub Actions использует `npm ci`, `npm audit --audit-level=moderate`, TypeScript check и production build.
- Обновлён Vite до 8.3.5 и React plugin до 6.2.1; npm audit на проверенной установке показал 0 уязвимостей. Учтено системное предпочтение `prefers-reduced-motion` в анимациях, где оно уже реализовано.

## Результат повторной проверки источника (03.11.2026)

- Claude получил `ROBOTS_DISALLOWED` при прямом автоматическом доступе и не обходил ограничение. Из-за отсутствия сетевого доступа Internet Archive, sitemap, WordPress REST API, XML-RPC и медиатека не были проверены. Архив Claude — заготовка файлов, а не извлечённая база.
- В индексированном снимке официальной карточки ЛТ-21 найдены описание, класс пулестойкости Бр3 и параметры. Локальная карточка создана с явным предупреждением о давности источника и необходимости проверки, в том числе необычного поля «предел огнестойкости 60 минут».

## Ограничения и точность

Не выдумывать характеристики, цены, сертификаты, сроки, гарантии, складские остатки, отзывы или юридические формулировки. Пять сохранённых названий/ссылок не являются полными карточками и не подтверждают полный каталог из 68 позиций. Число 68 пока является целью восстановления, а не подтверждённым количеством доступных карточек.

## Запуск

Node.js 22.12+ или 24.x; CI использует 24.x, затем `npm ci` и `npm run dev`. Production-сборка: `npm run build`. TypeScript check: `npx tsc --noEmit`. Проверка зависимостей: `npm audit --audit-level=moderate`.
