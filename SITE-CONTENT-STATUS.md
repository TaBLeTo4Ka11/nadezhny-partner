# Состояние сайта «Надёжный партнёр»

## Реализовано в рабочей ветке gpt6/site-completion

- Главная страница с адаптивной навигацией, каталогом, блоками о компании, производстве, галереей, отзывами, контактами и формой запроса КП.
- Светлый дизайн с графитовой типографикой и красными акцентами.
- Структура текущей ветки: 3 группы и 13 категорий из ранее доступной индексированной версии главной страницы. Это не результат полного обхода сайта; в повторном отчёте Claude указан `ROBOTS_DISALLOWED`. Его отчёт также содержит альтернативный подсчёт 6 групп/19 пунктов из файлов репозитория; это расхождение пока не разрешено первоисточником.
- Отдельные локальные маршруты для 13 категорий: `/catalog/<slug>/`; неизвестные адреса показывают клиентский экран 404. Из-за SPA rewrite HTTP-статус 404 пока не гарантирован.
- Поиск по названиям категорий и группам; совпадение с названием группы показывает все категории этой группы.
- В данных проекта сохранены пять названий и URL карточек банковских передаточных устройств из предыдущего извлечения. Полные карточки не восстановлены; повторная проверка Claude не смогла независимо подтвердить страницы.
- В текущих данных есть пять ссылок на изображения продукции, 11 фотографий объектов, 13 фотографий производства, три отзыва и шесть логотипов партнёров. Все изображения пока внешние; 24 URL фотографий объектов/производства содержат размеры миниатюр `225x300` или `169x300`. Оригиналы не скачаны и не проверены.
- Отдельные информационные маршруты склада, доставки и установки, вакансий и полезных материалов. Их тексты не восстановлены: страницы честно сообщают об этом и дают ссылку на оригинал.
- Динамические title/description и canonical для категорий и информационных страниц; неизвестные адреса получают `noindex, nofollow`.
- Категории и информационные страницы помечены `noindex, follow`, пока их контент не восстановлен и не проверен.
- `robots.txt` указывает на XML sitemap.
- XML sitemap намеренно содержит только главную страницу: остальные локальные страницы пока закрыты от индексации через `noindex`.
- Форма КП собирает контактные данные и описание задачи, позволяет выбрать файл и открывает почтовое приложение. Файл нужно приложить вручную.
- Зафиксированы версии зависимостей в `package-lock.json`; GitHub Actions использует `npm ci`, `npm audit --audit-level=moderate`, TypeScript check и production build.
- Обновлён Vite до 8.3.5 и React plugin до 6.2.1; npm audit на проверенной установке показал 0 уязвимостей. Учтено системное предпочтение `prefers-reduced-motion` в анимациях, где оно уже реализовано.

## Результат повторной проверки источника (03.11.2026)

- Claude получил `ROBOTS_DISALLOWED` при прямом автоматическом доступе и не обходил ограничение. Из-за отсутствия сетевого доступа Internet Archive, sitemap, WordPress REST API, XML-RPC и медиатека не были проверены. Архив Claude — заготовка файлов, а не извлечённая база.
- В поисковой выдаче найден только частичный фрагмент описания устройства ЛТ-21: огнестойкость 60 минут, высота 1800–2950 мм, ширина 800–1200 мм. Это не полная карточка; характеристики пока не публикуются на сайте.

## Что остаётся

- Повторно извлечь полный исходный каталог, проверить все карточки, характеристики и фотографии по первоисточнику.
- Перенести подтверждённые изображения в репозиторий и проверить их соответствие товарам.
- Перенести и проверить оригинальные тексты политики конфиденциальности и cookie; согласие в форме требует отдельной юридической проверки.

- При необходимости SEO-строгого HTTP 404 заменить общий SPA fallback на точечную маршрутизацию или статическую генерацию известных страниц.
- Проверить актуальный deployment Preview после последних изменений и Production после согласованного merge.
- Проверить реквизиты, контакты, часы работы и права на изображения с владельцем компании.
- После восстановления и проверки контента пересмотреть `noindex` и добавить подтверждённые страницы в sitemap.
- Проверить production deployment Vercel после снятия ограничения платформы.

## Ограничения и точность

Не выдумывать характеристики, цены, сертификаты, сроки, гарантии, складские остатки, отзывы или юридические формулировки. Пять сохранённых названий/ссылок не являются полными карточками и не подтверждают полный каталог из 68 позиций. Число 68 пока является целью восстановления, а не подтверждённым количеством доступных карточек.

## Запуск

Node.js 22.12+ или 24.x; CI использует 24.x, затем `npm ci` и `npm run dev`. Production-сборка: `npm run build`. TypeScript check: `npx tsc --noEmit`. Проверка зависимостей: `npm audit --audit-level=moderate`.
