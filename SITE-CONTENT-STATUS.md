# Состояние сайта «Надёжный партнёр»

## Реализовано в рабочей ветке gpt6/site-completion

- Главная страница с адаптивной навигацией, каталогом, блоками о компании, производстве, галереей, отзывами, контактами и формой запроса КП.
- Светлый дизайн с графитовой типографикой и красными акцентами.
- Каталог: 3 группы и 13 категорий, сверенные с доступной версией главной страницы исходного сайта.
- Отдельные локальные маршруты для 13 категорий: `/catalog/<slug>/`; неизвестные адреса показывают страницу 404.
- Поиск по названиям категорий и группам; совпадение с названием группы показывает все категории этой группы.
- Пять подтверждённых товарных позиций банковских передаточных устройств со ссылками на исходные карточки. Это не полный каталог.
- Пять изображений продукции, 11 фотографий объектов, 13 фотографий производства, три отзыва и шесть логотипов партнёров — по данным текущих файлов проекта; адреса изображений пока внешние.
- Отдельные информационные маршруты склада, доставки и установки, вакансий и полезных материалов. Их тексты не восстановлены: страницы честно сообщают об этом и дают ссылку на оригинал.
- Динамические title/description и canonical для категорий и информационных страниц; неизвестные адреса получают `noindex, nofollow`.
- Категории и информационные страницы помечены `noindex, follow`, пока их контент не восстановлен и не проверен.
- `robots.txt` указывает на XML sitemap.
- XML sitemap намеренно содержит только главную страницу: остальные локальные страницы пока закрыты от индексации через `noindex`.
- Форма КП собирает контактные данные и описание задачи, позволяет выбрать файл и открывает почтовое приложение. Файл нужно приложить вручную.
- Зафиксированы версии зависимостей в `package-lock.json`; GitHub Actions использует `npm ci`, `npm audit --audit-level=moderate`, TypeScript check и production build.
- Обновлён Vite до 8.3.5 и React plugin до 6.2.1; npm audit на проверенной установке показал 0 уязвимостей. Учтено системное предпочтение `prefers-reduced-motion` в анимациях, где оно уже реализовано.

## Что остаётся

- Повторно извлечь полный исходный каталог, проверить все карточки, характеристики и фотографии по первоисточнику.
- Перенести подтверждённые изображения в репозиторий и проверить их соответствие товарам.
- Перенести и проверить оригинальные тексты политики конфиденциальности и cookie; согласие в форме требует отдельной юридической проверки.
- Решить, нужен ли backend для заявок и загрузки файлов; сейчас серверной отправки, хранения файлов, антиспама и CRM-интеграции нет.
- Проверить все ссылки, маршруты, мобильную и настольную версии на реальных устройствах.
- Проверить актуальный deployment Preview после последних изменений и Production после согласованного merge.
- Проверить реквизиты, контакты, часы работы и права на изображения с владельцем компании.
- После восстановления и проверки контента пересмотреть `noindex` и добавить подтверждённые страницы в sitemap.
- Проверить production deployment Vercel после снятия ограничения платформы.

## Ограничения и точность

Не выдумывать характеристики, цены, сертификаты, сроки, гарантии, складские остатки, отзывы или юридические формулировки. Пять подтверждённых товарных позиций не являются полным каталогом из 68 карточек. Число 68 пока является целью восстановления, а не подтверждённым количеством доступных карточек.

## Запуск

Node.js 20.19+ или 22.12+, затем `npm ci` и `npm run dev`. Production-сборка: `npm run build`. TypeScript check: `npx tsc --noEmit`. Проверка зависимостей: `npm audit --audit-level=moderate`.
