# Состояние сайта «Надёжный партнёр»

## Что уже включено в основную ветку main

- Главная страница и мобильная/десктопная навигация.
- Раздел каталога с 7 направлениями и 5 фотографиями продукции.
- Раздел «О компании» с общим описанием и 4 сворачиваемыми этапами производства.
- Отдельная галерея из 13 фотографий производства.
- Галерея из 11 фотографий реализованных объектов.
- 3 отзыва, перенесённых с оригинального сайта: первый опубликован без имени, далее Алия и Мария.
- Форма запроса коммерческого предложения, контакты, карта и реквизиты.
- Автоматическая проверка сборки через GitHub Actions (workflow добавлен; выполнение нужно проверить в Actions).

## Что ещё не восстановлено полностью

- Полный каталог из 68 карточек товаров с характеристиками, размерами, вариантами исполнения и отдельными страницами.
- Все 24 категории в точном виде. Сейчас восстановлены 7 видимых групп и их основные позиции из меню.
- Все изображения партнёров и фотографии, приложенные к отзывам.
- Полные страницы «Склад», «Доставка и установка», «Вакансии», «Полезное».
- Реальная серверная отправка формы, прикрепление файлов и защита от спама. Сейчас форма формирует письмо через почтовое приложение.
- Политика конфиденциальности и согласие на cookie: ссылки в старом интерфейсе пока требуют привязки к проверенным текстам.
- Локальное хранение оригинальных фотографий: сейчас изображения загружаются с iv-partner.ru.

## Важные оговорки

- Не создавать характеристики, сертификаты, цены, сроки и гарантии без источника.
- Не публиковать устаревшие банковские реквизиты без сверки с владельцем компании.
- Не выдавать 5 изображений продукции за полный каталог.
- Не считать сайт готовым к публикации, пока не пройдена сборка и визуальная проверка на телефоне и компьютере.

## Запуск локально

Установить Node.js 20+, выполнить `npm install`, затем `npm run dev`. Для production-сборки — `npm run build`.
