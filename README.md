# Надёжный партнёр

Корпоративный сайт компании «Надёжный партнёр» — производство, поставка и монтаж противопожарных преград и специальных дверей.

## Визуальное направление

Основная версия — светлая корпоративная тема в стилистике оригинального сайта:
- белый фон и светло-серые поверхности;
- графитовая типографика;
- фирменные красные акценты;
- фотографии продукции, производства и реализованных объектов;
- адаптивная навигация для телефона и компьютера.

Тёмная концепция хранится отдельно и не является темой этой версии.

## Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS
- GSAP + ScrollTrigger

## Разделы сайта

- Главная
- Каталог и ссылки на исходные категории
- Партнёры
- О компании и сворачиваемые этапы производства
- Фотографии производства
- Наши работы
- Отзывы
- Запрос коммерческого предложения
- Контакты и карта

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Важные ограничения перед публикацией

- Полная выгрузка всех 68 карточек каталога с характеристиками ещё не завершена.
- Часть изображений пока загружается с исходного домена iv-partner.ru.
- Формы открывают почтовое приложение с заполненным письмом. Серверной отправки, загрузки вложений и антиспам-защиты пока нет.
- Страницы склада, доставки и юридические документы пока открываются на исходном сайте.
- Банковские реквизиты и контактные данные необходимо подтвердить у владельца компании перед запуском.
- Перед публичной публикацией нужно проверить сайт визуально на телефоне и компьютере и подключить домен/хостинг.
