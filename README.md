# Надёжный партнёр

Корпоративный сайт компании «Надёжный партнёр».

## Стек
- React 18 + TypeScript
- Vite + Tailwind CSS
- GSAP + ScrollTrigger

## Запуск
Node.js 20 или новее:

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`.

## Контент и ограничения
- Каталог содержит 13 категорий, перенесённых с главной страницы официального сайта.
- Подтверждены только пять карточек банковских лотков; остальные характеристики и карточки не выдумываются.
- Фото и часть ссылок пока загружаются с iv-partner.ru.
- Разделы склада, доставки, вакансий и полезной информации пока ведут к исходным страницам.
- Формы пока формируют письмо через почтовое приложение. Файлы не загружаются, серверной отправки, антиспама и CRM-интеграции нет.
- До запуска владелец должен подтвердить юридические/банковские реквизиты, актуальность контактов, права на изображения и текст согласия на обработку персональных данных.
- Перед публикацией проверьте домен, canonical/ sitemap, формы и все внешние ссылки на production-домене.

## Безопасность
Vercel response headers are configured in `vercel.json`. No backend endpoints or credentials are included in the frontend. Do not add API secrets to client-side environment variables.
