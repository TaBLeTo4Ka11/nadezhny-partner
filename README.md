# Надёжный партнёр

Корпоративный сайт производителя противопожарных дверей и конструкций.

Стек: React, TypeScript, Vite, Tailwind CSS, GSAP + ScrollTrigger.

Перед публикацией необходимо добавить проверенные материалы компании, каталог, реальные фото, контакты, реквизиты и политику конфиденциальности.
